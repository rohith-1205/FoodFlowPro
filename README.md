# FoodFlow Pro - Smart Restaurant Ordering & Management System

Welcome to the FoodFlow Pro project! This is a full-stack web application designed for a Software Engineering Assignment. It manages restaurant operations including ordering, kitchen management, delivery tracking, and user authentication across multiple roles.

## Tech Stack
* **Frontend:** React.js, Vanilla CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Real-time:** Socket.io

## User Roles
1. Customer
2. Waiter
3. Kitchen Staff
4. Delivery Partner
5. Manager
6. Administrator

## Project Structure
* `/frontend` - React application (User Interface)
* `/backend` - Node.js/Express API (Server & Database logic)

## Next Steps for Setup
Navigate into the respective directories and install the dependencies:

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm start
```
